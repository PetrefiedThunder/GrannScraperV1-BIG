# Frontend QA pass

PR: opened by orchestrator

CI status: pending at time of writing

Counts: Critical=0 High=4 Medium=1 Low=0

Scope: the plain HTML/JavaScript dashboard in `scraper/web/static/`, its asset routing, and its contract with the FastAPI API. This is a real UI; no substitution was needed. There is no frontend package manifest, TypeScript application, component-test framework, or build command. JavaScript syntax validation and focused browser tests are the appropriate checks for this surface.

## Evidence and outcome

- Final browser run: **23 accepted test executions: 14 ordinary passes, 9 expected failures, 0 unexpected failures, 0 skipped**. Playwright displays `23 passed` because `test.fail` expectations matched; nine assertions still expose real product bugs. [Final command output](artifacts/frontend-final-browser-suite-c390dc50.txt), [structured report](artifacts/frontend-playwright.json), [expectation/actual summary](artifacts/frontend-final-result-summary-815384ae.txt).
- Chromium 153.0.8010.12 ran all 19 cases. Firefox 155.0 and WebKit 26.6 each passed two smoke journeys: analyze/create/run/list and view/close results. Engines were verified by actual user agents, not the requested connection label. [Engine probe](artifacts/frontend-browser-engines.json).
- `node --check scraper/web/static/app.js` passed. No frontend build, TypeScript check, or existing JavaScript unit suite applies. [Syntax output](artifacts/frontend-javascript-syntax-b91f6a67.txt).
- Mocks use the real API response shape. The captured create payload is validated by production `ScrapeJob`, not a JavaScript approximation. Backend QA independently reproduced FE-001/002/003 against the actual ASGI routes. [Backend unquarantined diagnostics](artifacts/backend-defect-reproduction-unquarantined-e6a8796c.txt).
- Positive checks cover empty jobs, submission order, concurrent/sequential selection, disabled submission while analysis waits, HTML boundary validation, cancel/confirm deletion, recovery after failed analysis, list outage handling, running-to-empty completion, null result cells, and closing details.
- Healthy mocked journeys produced no console errors, failed requests, or blocked external requests. Root navigation produces the expected script 404. All API requests are intercepted and any non-loopback non-API traffic is blocked. [Chromium flow](artifacts/frontend-main-flow-chromium.json), [Firefox flow](artifacts/frontend-main-flow-firefox.json), [WebKit flow](artifacts/frontend-main-flow-webkit.json), [root error record](artifacts/frontend-root-errors.json).

The browser static server intentionally mirrors FastAPI's `/` and `/static` mounts; it does not invent a successful `/app.js` route. Downstream interface checks use `/static/index.html` as an explicit workaround for FE-001. Those checks do not establish that the real root dashboard works.

## Performance and coverage

The final unthrottled local list/details run measured DOMContentLoaded **17 ms**, load **17 ms**, and first contentful paint **24 ms** in Chromium. These are local diagnostic numbers with mocked API responses; they are **not** Lighthouse scores, production performance, throttled-mobile measurements, or evidence for actual scraping latency. [Performance and V8 report](artifacts/frontend-performance.json).

No pre-existing frontend coverage suite exists, so before-coverage is **not measured**, not 0%. The new diagnostic list/details journey executed **6,087 / 10,747 UTF-16 source units (56.64%)** of `app.js` using V8 range coverage. This is a narrowly defined code-unit metric, **not line/branch coverage and not aggregate coverage of all 23 executions**. Backend coverage is reported centrally in `COVERAGE.md`; no invalid before/after frontend percentage comparison is claimed.

// Probe only the supplied browser server. Never launch or install a browser.
const { chromium, firefox, webkit } = require('playwright');
const fs = require('node:fs');
const path = require('node:path');

(async () => {
  const results = [];
  for (const [requested, browserType] of Object.entries({ chromium, firefox, webkit })) {
    let context;
    try {
      const browser = await browserType.connect(process.env.PW_TEST_CONNECT_WS_ENDPOINT || 'ws://127.0.0.1:3950/', { timeout: 4000 });
      context = await browser.newContext({ serviceWorkers: 'block' });
      await context.route('**/*', route => route.abort('blockedbyclient'));
      const page = await context.newPage();
      const userAgent = await page.evaluate(() => navigator.userAgent);
      const actualEngine = /Firefox\//.test(userAgent) ? 'firefox' : /Chrome\//.test(userAgent) ? 'chromium' : /AppleWebKit\//.test(userAgent) ? 'webkit' : 'unknown';
      results.push({ requested, actualEngine, version: browser.version(), userAgent, supportedAsRequested: actualEngine === requested });
    } catch (error) {
      results.push({ requested, supportedAsRequested: false, error: error.message });
    } finally {
      if (context) await context.close();
    }
  }
  fs.writeFileSync(path.resolve(__dirname, '../../docs/qa/2026-10-02/artifacts/frontend-browser-engines.json'), JSON.stringify(results, null, 2));
  console.log(JSON.stringify(results, null, 2));
  // Closing the process releases client connections; never stop the supplied server.
  process.exit(0);
})().catch(error => { console.error(error); process.exit(1); });
